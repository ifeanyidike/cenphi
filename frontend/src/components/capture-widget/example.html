📝 Simplified Testimonial Widget

A clean, modern, and professional testimonial capture widget that focuses on what matters most - capturing authentic customer experiences through video and text.

✨ Key Features

The simplified widget removes complexity and focuses on essential functionality:

🎥 Video Testimonials

Record videos directly using device camera with portrait orientation, or upload existing video files.

✍️ Text Testimonials

Simple text input for written testimonials with character counting and validation.

🎨 Professional Design

Minimal, elegant interface with customizable colors, positioning, and branding options.

📱 Mobile Optimized

Works seamlessly across all devices with responsive design and touch-friendly controls.

⚡ Simple Integration

Easy to embed with just a script tag and minimal configuration required.

🚀 Fast & Lightweight

Removed complex features like WebSockets, AI, and multi-step flows for better performance.

🛠️ Configuration Example

Configure the widget by setting window.testimonialWidgetConfig before loading the script:

<script> window.testimonialWidgetConfig = { campaignId: 'your-campaign-id', apiBaseUrl: 'https://your-api.com/api', companyName: 'Your Company', companyLogo: 'https://your-logo-url.com/logo.png', buttonText: 'Share Your Experience', question: 'What has your experience been like with our product?', primaryColor: '#4F46E5', secondaryColor: '#8B5CF6', position: 'bottom-right', maxDuration: 120, darkMode: false, brandMode: 'gradient', roundedCorners: 'rounded' }; </script> <script src="https://your-cdn.com/testimonial-widget.js"></script>

🎯 What Was Removed

To create a more focused and maintainable widget, we removed:

  • Multi-step flows - Simplified to single-page interactions
  • Profile picture uploads - Removed unnecessary complexity
  • Audio-only testimonials - Focus on video and text only
  • Image testimonials - Streamlined to core formats
  • AI features and live translation - Removed real-time processing
  • WebSocket connections - Eliminated streaming dependencies
  • Complex navigation - Single modal with clear flow
  • Excessive configuration options - Focused on essential settings

📋 Supported Formats

Video Formats

Recording: WebM format with VP9/Opus codecs
Upload: MP4, WebM, MOV, AVI (up to 1GB)

Text Input

Plain text with 1000 character limit, automatic validation and word counting.
